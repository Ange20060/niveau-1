# Exercice 4 — Sur GitHub

Objectif : relier ton dépôt local à un dépôt distant et découvrir le travail
collaboratif.

## À faire

1. Crée un compte GitHub si ce n'est pas déjà fait.
2. Crée un nouveau dépôt **vide** sur GitHub (sans README pour l'instant).
3. Relie ton dépôt local à ce dépôt distant, puis pousse ton `main` dessus.
4. Vérifie sur le site que tes fichiers et ton historique sont bien là.
5. Crée une branche, fais une modification, pousse cette branche, puis ouvre
   une **pull request** sur GitHub. Lis ce que l'interface te montre (la
   comparaison des changements), puis fusionne-la.
6. Récupère la version fusionnée en local.

## Questions

- Quelle est la différence entre ton dépôt **local** et le dépôt **distant** ?
- À quoi sert une **pull request** dans une équipe ?
- Quelle commande récupère les changements du distant vers ton local ?

## Indices

- `git remote add origin <url>`, `git push -u origin main`, `git pull`.
- Configure l'authentification GitHub (cherche « github token
  d'authentification » ou « clé SSH github »).
