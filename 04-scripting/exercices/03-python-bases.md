# Exercice 3 — Python : la calculatrice

Objectif : écrire un petit programme Python avec entrées, conditions et
fonctions.

## À faire

1. Écris un programme `calculatrice.py` qui demande à l'utilisateur deux
   nombres et une opération (`+`, `-`, `*`, `/`).
2. Il affiche le résultat.
3. Gère le cas de la division par zéro (afficher un message clair au lieu de
   planter).
4. Mets le calcul dans une **fonction** `calculer(a, b, operation)`.
5. Bonus : recommence en boucle tant que l'utilisateur ne tape pas `q`.

## Questions

- Quelle fonction Python lit une saisie clavier ? Que renvoie-t-elle (quel
  type) ?
- Pourquoi faut-il convertir la saisie avant de faire un calcul ?
- À quoi sert de mettre le calcul dans une fonction plutôt qu'en ligne ?

## Indices

- `input()`, `int()` ou `float()`, `if/elif/else`, `def`, une boucle `while`.
